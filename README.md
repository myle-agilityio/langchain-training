# langchain-training

## OVERVIEW
This document presents the training roadmap for LangChainJS, LangGraph, and their integration, designed specifically for Node.js and Next.js developers. It includes dedicated time for reading and hands‑on practice, following the official documentation available at this [link](https://docs.langchain.com/oss/javascript/langchain/overview).
## TIMELINE
Total: 2 weeks (10 days).
## TARGETS
After completing the training course, trainees are expected to achieve the following outcomes:
### LangChainJS
- Grasp how Agents, Models, and Tools interact to build intelligent workflows.
- Design predictable responses using message templates and schema validation.
- Manage conversational context effectively.
- Apply prebuilt and custom middleware for enhanced control and extensibility.
- Improve user experience through real‑time event streaming.
### LangGraph
- Orchestrate multi‑step logic using graph‑based execution.
- Ensure long‑running tasks and state recovery.
- Handle interrupts and time travel — debug or rewind execution flows safely.
- Build integrated AI systems — combine LangChainJS logic with LangGraph orchestration for scalable, maintainable AI solutions.
## PREREQUISITES
Required
- A modern operating system: macOS, Linux, or Windows.
- An IDE with TypeScript support (e.g., Visual Studio Code or Cursor).
- Node.js version 24.x or higher.
- Pnpm version 10.x or higher.
- Access to an LLM API Key:
  - OpenAI API Key → Visit https://platform.openai.com, create an account, and generate your API key.
  - Google AI API Key → Visit https://ai.google.dev, sign up, and create your API key.
