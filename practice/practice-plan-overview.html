Practice Plan — Overview

AI Email Assistant

A support-inbox assistant built on LangChain.js and LangGraph, integrated with CopilotKit for a live, shared-state chat + app experience. Classifies incoming mail, drafts responses with a human always in the loop, and hands off between agents for the harder cases.

Learning objectives

what the practice targets

LangChain.js

  • Composition — how agents, models, and tools interact
  • Predictability — message templates & schema validation
  • Context — managing conversational state
  • Middleware — prebuilt and custom, for control & extensibility
  • Streaming — real-time events for a responsive UI

LangGraph

  • Orchestration — graph-based, multi-step execution
  • Durability — long-running tasks & state recovery
  • Control — interrupts and time travel
  • Integration — LangChain.js logic inside LangGraph flows
Where the schedule is tight

Day 5 bundles five distinct advanced concepts — memory, guardrails, replay, forked drafts, and agent handoff — into a single day. That's the highest-risk point in the plan for a solo developer.

Multi-agent handoff is scoped as a stretch goal: everything else in Phase 2 stands on its own if it needs to be dropped.
